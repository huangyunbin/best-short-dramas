# Best Short Dramas 🎬

> A hand-sorted list of **1030 English short dramas** (vertical micro-dramas) grouped by trope — billionaire, revenge, rebirth, werewolf, secret baby and more. Every title links to its full episode list on [DramaBee](https://dramabee.app).

Short dramas are vertical series with 1–2 minute episodes, the kind you find on ReelShort, DramaBox or TikTok. This list only keeps complete series (20+ episodes) whose streams start reliably.
